# Vision-based Pick-and-Place in Cluttered Environments
An NVIDIA Isaac Sim/Lab project for creating a full pipeline to accomplish vision-based pick-and-place tasks in clutter. This project uses SOTA reinforcement learning techniques to train a policy controlling a UR5E, and uses synthetic data generation to train a perception model to localize objects.
